# India House Price Prediction 🏡

## Project Overview
The India House Price Prediction project aims to analyze housing data and predict house prices using Python and machine learning techniques.

This project is developed as part of the Business and Data Analytics internship at YBI Foundation.

## Objectives
- Analyze the Indian housing dataset.
- Clean and prepare data for analysis.
- Explore patterns and relationships in housing prices.
- Build a machine learning model to predict house prices.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
1. Load the dataset.
2. Explore and understand the data.
3. Check and remove duplicate records.
4. Perform exploratory data analysis (EDA).
5. Visualize housing price distributions.
6. Prepare features and target variables.
7. Split data into training and testing sets.
8. Train and evaluate a machine learning model.

## Dataset
India House Price dataset 

## Expected Outcome
To understand housing price patterns and apply data analysis and machine learning techniques to house price prediction.

Thanks to YBI Foundation for providing the learning opportunity and project dataset.
